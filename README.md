# vmgames.com.br

Site dos jogos da **VM Games** (Arley Vieira, Catalão/GO).

Conteúdo:

- `app-ads.txt` — autorização de vendedor do AdMob, exigida na raiz do domínio
- Páginas e políticas de privacidade de Turbo Race, Sky Vanguard e Sugar Strike
- `sugar-strike/jogar/` — o jogo rodando direto no navegador

Site estático puro: sem framework, sem build, sem dependência externa.
Publicado por GitHub Pages; cada `git push` na branch `main` atualiza o site.
